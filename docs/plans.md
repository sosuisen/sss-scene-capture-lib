# plans

TDDで現在対象としているタスクの作業用todo。使い捨て。

### テストリスト

- [ ] PCのシステムサウンドを記録する
  - [x] 録音を開始すると、Streamを返す。
  - [x] 録音を1秒間実行すると、1秒分の録音データが生成される。
  - [ ] 録音中に無音の区間があっても、その区間のデータが記録される。
  - [x] 録音開始直後の無音は記録されない。最初に音が届いた時点から記録が始まる。
  - [ ] 一度音が届いた後の無音は記録される。

### 実装メモ（振る舞いではなく方針。決定したらADR-002に移す）

- ループバックは何も再生されていないとデータを配らないことがある。録音中は同じ再生デバイスにゼロを書き続ける出力ストリームを流し、常にデータが届く状態を作る。
