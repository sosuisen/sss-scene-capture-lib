# sss-scene-capture

アプリの画面とサウンドを記録するCLIツール。
1回のセッションにつき、開始時の画面を1枚の静止画として保存、開始から終了までの音声を保存する。

ユーザーは開発者（わたし）本人。

1. アクティビティ
2. タスク
3. ウォーキングスケルトン

- 開始する #わたし
  - 開始操作する
    - [x] Enterキーを押す
      - 対象をフルスクリーンかウィンドウか選ぶ
        - Javaから呼ぶ
  - カウントダウンを始める #アプリ
    - [x] 3,2,1カウントダウンで開始
    - [x] 開始状態を表示
- 記録する #アプリ
  - 画面を記録する
    - [x] プライマリーモニター全体のスクリーンショットを1枚撮る
      - 指定ウィンドウのスクリーンショットを1枚撮る
  - サウンドを記録する
    - [x] PCのシステムサウンドを記録する
- 停止する #わたし  
  - 停止操作する
    - [x] Enterキーを押す
  - 保存する #アプリ
    - [ ] 停止後、日時名フォルダに、screen.pngとsound.wavが保存される
      - サウンドはMP3に変換してから保存される。
