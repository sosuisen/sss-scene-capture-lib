# sss-scene-capture

アプリの画面とサウンドを記録するCLIツール。
1回のセッションにつき、開始時の画面を1枚の静止画として保存、開始から終了までの音声を保存する。

ユーザーは開発者（わたし）本人。

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. ターミナルアプリ版
5. 外部連携
6. ウィンドウ指定

- 開始する #わたし
  - 開始操作する
    - [x] Enterキーを押す
      - [x] v Javaから呼ぶ
        - 対象をフルスクリーンかウィンドウか選ぶ
  - ~~カウントダウンを始める~~ #アプリ
    - [x] 3,2,1カウントダウンで開始
    - [x] 開始状態を表示
- 記録する #アプリ
  - 画面を記録する
    - [x] プライマリーモニター全体のスクリーンショットを1枚撮る
      - vv 指定ウィンドウのスクリーンショットを1枚撮る
  - サウンドを録音する
    - [x] 最初の無音区間は録音されない。
    - [x] PCのシステムサウンドを録音する
- 停止する #わたし  
  - 録音を停止する
    - [x] Enterキーを押す
  - 画面を再記録して置き換えてよい
    - [x] v s+Enterで、現在のプライマリーモニターのスクリーンショットで置換される。
  - 保存して次の記録開始 #アプリ
    - [x] 日時名フォルダに、screen.pngとsound.wavが保存される
      - [x] ^ サウンドはMP3に変換して保存することもできる。
        - [x] Enterで、保存して次の記録開始
- 終了する #わたし
  - アプリを終了する
    - Ctrl+Cで終了
      - [x] q+Enterで、アプリ終了
